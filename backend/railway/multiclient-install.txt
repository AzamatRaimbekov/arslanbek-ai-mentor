ARSLANBEK — CLAUDE CODE, CODEX И ПРИЛОЖЕНИЯ С MCP

Нужны Python 3 и приложение с поддержкой скиллов или локального MCP.
Полностью распакуйте архив. Команды ниже запускаются из распакованной папки.
На Windows используйте WSL для Claude Code; для других клиентов — среду,
в которой доступны Python 3 и ваше приложение.

CODEX
python3 install.py --client codex

Скилл устанавливается в ~/.agents/skills/arslanbek-ai-mentor,
хуки — в ~/.codex/hooks.json, MCP — в ~/.codex/config.toml.
Существующие настройки сохраняются. Начните новую сессию и вызовите:
$arslanbek-ai-mentor
Просмотрите и доверьте хуки в Codex. Это отдельное требование приложения;
пока хуки не доверены, автоматическая запись запросов не работает.

CLAUDE CODE
python3 install.py --client claude-code

Начните новую сессию и вызовите /arslanbek-ai-mentor.
Скилл находится в ~/.claude/skills/arslanbek-ai-mentor.
Также можно поместить папку arslanbek-ai-mentor туда вручную: при первом
вызове наставник подключит хуки и предложит выбрать режим передачи данных.

ДРУГИЕ ПРИЛОЖЕНИЯ / DEEPSEEK
python3 install.py --client mcp

Добавьте созданный mcp.json в настройки MCP вашего приложения, а SKILL.md —
в его инструкции. Установщик покажет точные пути к этим файлам.
Модель может быть любой. Необходимы локальные MCP-инструменты: обычный
браузерный чат без MCP или исполнения команд сбор не поддерживает.
Без хуков агент вызывает arslanbek_record_prompt для текущего запроса и
arslanbek_submit_progress для сводки. Полнота записи запросов зависит от
вызовов инструментов агентом; установка сама по себе этого не гарантирует.

ПЕРЕДАЧА ДАННЫХ
При первой установке выберите «Установить и включить сбор» или «Установить
без сбора». Выбор сохраняется отдельно для каждого приложения; повторного
вопроса в чате не будет. При обновлении сохраняются прежний выбор, личный
профиль и уроки. Этот архив не содержит school-policy.json и не включает
передачу на основании предполагаемого договора.

При включённом сборе школа получает из выбранного приложения во всех проектах:
тексты новых запросов, имя проекта, идентификатор сессии, название приложения
и модели, если оно известно; сводки задач и наблюдений о навыках; имя/email
из доступного аккаунта Claude и Git, имя компьютера и ОС. Данные видит
администратор школы. Прошлая переписка, ответы агента и исходные файлы проектов
не загружаются. Типовые секреты скрываются по шаблонам, но полное удаление
всех секретов не гарантируется. Настройки подключения школы уже в архиве;
пароль администратора вводить не нужно.

КАРТА ПРОГРЕССА
После содержательной работы, проверки результата или препятствия наставник
составляет сводку в текущей рабочей сессии. В ней: задача, цель, этап,
направления, вклад человека и ИИ, навыки с подтверждениями, проверки,
препятствия и следующие действия с критериями готовности.
В длинной сессии хуки напоминают о сводке на третьем запросе и затем каждые 15.
Правила формата: references/progress-report.md. Сервер хранит и показывает
сводки в карточке участника и ленте «Сводки»; внешний серверный ИИ не вызывается.
Отсутствие наблюдений означает «нет данных», а не «слабый навык».

ПРОВЕРКА ДОСТАВКИ
В MCP вызовите arslanbek_status. Для Claude Code:
python3 ~/.claude/skills/arslanbek-ai-mentor/scripts/telemetry.py status
Для Codex:
python3 ~/.agents/skills/arslanbek-ai-mentor/scripts/telemetry.py status
При отсутствии сети данные остаются в локальной очереди. Следующая попытка —
при новом запросе, сводке или запуске сессии. Доставку подтверждает дата
последней успешной передачи; пустая очередь сама по себе её не подтверждает.

ВЫКЛЮЧИТЬ СБОР
Из папки установленного скилла выполните:
python3 scripts/telemetry.py consent no
Остановится сбор в этом приложении, неотправленная очередь очистится.
Ранее доставленные данные автоматически не удаляются; обратитесь в школу.

ОБНОВЛЕНИЕ
Скачайте новый архив и повторите команду установки для вашего приложения.
Личный профиль, уроки, другие настройки и прежний выбор передачи сохраняются.
Для изменения выбора добавьте --choose-collection.
