# Подключение в настольном приложении

Служебные команды выполняешь ты. Не проси сотрудника открывать терминал,
запускать install.py или искать Python. Не меняй режим разрешений приложения.

## Codex и вкладка Code в Claude Desktop

При первом использовании или отсутствии подключения сам запусти
`scripts/bootstrap.py` из абсолютного пути к этому скиллу. В Codex добавь
`--client codex`, в Claude Code — `--client claude-code`.
Bootstrap сохраняет другие настройки, подключает MCP/хуки и проверяет доставку.
Обновления сохраняют личный профиль и прежнее отключение сбора.

На Windows пакет содержит собственный Python, установки в систему не требуется:

- x64: `<skill>/runtime/windows-x64/python.exe`;
- ARM64: `<skill>/runtime/windows-arm64/python.exe`.

Архитектуру узнай из среды ОС, не угадывай по имени компьютера. В PowerShell
запускай исполняемый файл оператором `&`, передавая путь и аргументы отдельно:

```powershell
& '<полный путь скилла>\runtime\windows-x64\python.exe' -X utf8 '<полный путь скилла>\scripts\bootstrap.py' --client codex
```

Если runtime отсутствует в старой копии, обнови школьный пакет. Не отправляй
пользователя устанавливать Bash/WSL ради нативного Windows-приложения.
В macOS/Linux используй доступный Python 3.10+ (`python3`), а последующие команды
запускай тем же интерпретатором. Если Python отсутствует, сообщи конкретную
причину; не называй подключение готовым.

В Codex пользователь должен просмотреть и доверить хуки в интерфейсе приложения.
Это отдельный контроль приложения, bootstrap его не обходит. MCP и новые хуки
могут потребовать новой сессии. До неё сводку можно отправить CLI-командой
`telemetry.py report --file <JSON>` тем же Python. Записывай текущий запрос через
`telemetry.py record-prompt --file <JSON>` только если для этой сессии хук ещё
не срабатывал; команда сама проверяет маркер и пропускает дубликат.

Нативная Windows-сессия и WSL — разные среды с разными домашними каталогами.
Подключай скилл внутри той среды, где работает агент. Для удалённой/cloud-сессии
локальная установка не устанавливает сбор на удалённую машину.

## Обычный чат Claude Desktop

Используется расширение `arslanbek-claude-desktop.mcpb`, устанавливаемое через
Settings → Extensions → Advanced settings → Install Extension.
Приложение само запускает MCP-сервер и управляет Python через UV. Нужна актуальная
версия Claude Desktop с поддержкой MCPB 0.4/UV; при первой установке нужен интернет.
Папка `.claude/skills` и CLI-хуки сами по себе не подключают обычный чат.

В чате нет UserPromptSubmit-хука: инструменты передают только запросы и сводки,
которые отправил агент. Не обещай полный автоматический журнал. Используй
arslanbek_status и при необходимости шаблон MCP `arslanbek_mentor`.
Сбор выключается в настройках расширения; ранее записанный отказ сохраняется.
