# Стандарт: ответ в чате + HTML

Для каждого финального ответа Ментора, включая короткое объяснение и уточняющий
вопрос, создавай HTML с тем же содержанием и добавляй ссылку в чат. Объявления
хода работы, вывод инструментов и структурированные отчёты школе остаются в своём формате.
Просьба «короче» уменьшает объём обеих версий. Явная просьба «только чат» отменяет
HTML для выбранного пользователем периода. Не меняй ответ после создания HTML:
если содержание изменилось, обнови обе версии до отправки.

## Подготовка

Составь ответ один раз как JSON. Обязательны `title` и непустой массив `sections`.
В каждом разделе — `title`, `kind` и содержимое. `kind`: `neutral`, `info`,
`success`, `warning`, `danger`, `action`. Это смысловые статусы: зелёный результат
и красная проблема должны иметь фактическое основание.

У текста поддерживаются **жирный акцент**, `код` и ссылки `[название](адрес)`.
Заголовок — обычным текстом. Пример формы данных, а не утверждение о проверках:

```json
{
  "title": "Разбор формы заявки",
  "summary": "Объясняю, что проверяем и кто выполняет следующий шаг.",
  "sections": [
    {
      "title": "Как проходит заявка",
      "kind": "info",
      "paragraphs": ["**Форма передаёт контакт продавцу.** Нужно проверить весь путь заявки."]
    },
    {
      "title": "Что требуется от тебя",
      "kind": "action",
      "ordered": true,
      "items": ["Открой страницу заявки.", "Отправь пробную заявку и скажи, появилось ли подтверждение."]
    }
  ]
}
```

Дополнительно: `icon` у раздела; `code` и `code_language` для реального кода/вывода;
`table: {"headers": ["…"], "rows": [["…"]]}`; `footnote` у документа.
Не ставь пустые разделы и не придумывай результаты ради оформления.

## Создание

Сохрани JSON во временный файл и сам выполни, подставив абсолютные пути:

```text
python3 <папка-скилла>/scripts/render_html.py --input <временный-ответ.json> --output <рабочая-папка>/.arslanbek/answers/<уникальное-имя>.html
```

Скрипт печатает готовый текст для чата со ссылкой на созданный HTML. Используй
этот текст в финальном сообщении: версии будут согласованы. Не предлагай пользователю
запускать служебную команду. В Claude Code путь начинается с `${CLAUDE_SKILL_DIR}`;
в Codex — с фактической папки загруженного скилла. На Windows используй Python,
который определён при подключении пакета (`references/desktop-start.md`).

HTML содержит встроенные стили, реальные цвета текста, отдельные карточки,
оглавление, светлую/тёмную тему и оформление для печати. Для обычного ответа
не нужны сеть, npm, сервер или установка библиотек. Сырой HTML экранируется.
Файл создаётся локально, не публикуется и не заменяет существующий файл.
Не добавляй HTML-ответы в учебную телеметрию.

## Перед отправкой

Убедись, что команда завершилась успешно и файл создан, затем дай реальную ссылку.
Результаты проверок и ограничения должны совпадать в обеих версиях. При изменении
шаблона проверь длинный ответ и узкий экран; повторять проверку браузером для каждого
обычного ответа не нужно. Браузер открывай по просьбе пользователя.

Если файл нельзя создать из-за ограничений среды, прямо сообщи об этом и дай
готовый самостоятельный HTML в блоке `html` либо через доступный механизм артефактов.
Не обещай файл или ссылку, которых нет. Код HTML не вставляй в обычный текст чата,
ожидая, что интерфейс превратит его в страницу.

## Дополнительный визуальный скилл

`visual-explainer` может помогать со схемами и интерактивными объяснениями, если
он фактически установлен и нужен задаче. Обычный HTML-ответ создаётся встроенным
скриптом без него. При совместном использовании сохраняй ответ в чате, согласуй
содержание HTML и чата, используй разрешённую рабочую папку и не открывай браузер
автоматически. Не устанавливай дополнительные зависимости для обычной карточки.
