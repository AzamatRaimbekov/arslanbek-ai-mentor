# Базовые скиллы во всех клиентах

Первый `scripts/bootstrap.py` сам подключает одиннадцать скиллов из `bundled/`:
`find-skills`, `vibecoding`, `mcp-setup`, `visual-explainer`, `using-superpowers`,
`brainstorming`, `writing-plans`, `test-driven-development`, `systematic-debugging`
`verification-before-completion` и `project-documentation-wiki`. Источники, лицензии и SHA-256 каждого файла
сохранены в `bundled/manifest.json` и папках скиллов. Не нужен отдельный плагин
Superpowers, сеть, npm или Bash для установки этого базового набора.

## Claude Code и Codex

В Claude Code скиллы копируются в `<CLAUDE_CONFIG_DIR>/skills/` либо
`~/.claude/skills/`; в Codex — в `~/.agents/skills/`. Явный `--skills-home` или
`ARSLANBEK_SKILLS_HOME` задаёт другой разрешённый каталог. Это адрес каталога
скиллов, а не изменение глобальных разрешений клиента.

Для повторной проверки агент выполняет, подставляя путь загруженного скилла:

```text
python3 <папка-скилла>/scripts/ensure_tools.py --client <claude-code|codex>
```

На Windows используй Python пакета из `references/desktop-start.md`, а не Bash
или предположение о наличии `python3`. Сотруднику служебные команды не выдавай.
После успешной установки объяви, какие скиллы добавлены. Если приложение ещё не
обновило каталог, используй встроенную копию инструкции в этой сессии; новые
скиллы доступны после обновления каталога или начала новой сессии.

Повторный запуск пропускает актуальные копии. Чужие скиллы, символьные ссылки и
личные изменения сохраняются. Обновляются только нетронутые копии, созданные этим
инструментом; состояние хранится в `.arslanbek-dependencies.json` у каталога скиллов.
`blocked`, `failed` и `not_ready` означают реальную проблему: не объявляй весь набор
готовым. Исправь конкретный пробел или обозначь недоступную возможность.

## Claude Desktop и другие MCP-клиенты

Встроенные скиллы входят в расширение. Вызови `arslanbek_list_skills`, затем
`arslanbek_read_skill` с именем подходящего скилла. Для его ссылки на ресурс передай
`path` из возвращённого списка файлов. Эти инструменты доступны и при отключённой
отправке данных школе, не изменяют настройки и не выполняют содержимое файлов.

Это инструкции для агента через MCP. Доступ к терминалу, файлам и другим серверам
определяется клиентом; наличие скилла не подключает эти возможности автоматически.
Команды `claude plugin` не запускай в Codex, Claude Desktop или другом MCP-клиенте.

## Дополнительный скилл под задачу

Проверь установленное, найди подходящий источник и прочитай его инструкции.
Подключай именно текущему нативному клиенту:

```text
python3 <папка-скилла>/scripts/ensure_tools.py --client codex --add owner/repo --skill skill-name
```

Для Claude Code используй `--client claude-code`. Внешняя установка использует
`npx skills add` с явным `--agent`, требует Node/npm и сеть. В нестандартный каталог
используй `skill-installer` с конкретным `--dest`; не подменяй HOME и не ставь в другой
клиент ради обхода ошибки. В MCP без терминала продолжай со встроенными скиллами.
`--with-stack` запрашивает расширенный стартовый набор, а не обязательную зависимость
каждого проекта. Не запускай его без потребности пользователя.

## Плагины Claude Code

`--with-plugins --client claude-code` подключает плагины Claude Code отдельно.
В Codex и MCP такой запрос получает `unsupported`, сохраняя рабочий базовый набор.
Существующий Ruflo исключает дублирующие `claude-mem` и ECC. Дополнительные плагины
не являются условием обычного ответа, HTML или подключения базовых скиллов.

Официальные пути Codex: [Build skills](https://learn.chatgpt.com/docs/build-skills).
Выбор клиента CLI: [vercel-labs/skills](https://github.com/vercel-labs/skills).
